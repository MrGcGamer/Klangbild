# Klangbild

Android-TV-App für Home Assistant und Music Assistant: zeigt groß, was gerade läuft – Cover, Titel und Künstler in ruhiger Typografie.

Besonders: Farben des Covers, Hue-Leisten, Hörbücher mit Kapiteln. Bei Pause wird der Fernseher zum Fensterblick: ein Papier-Diorama mit Bergen, Wald und Lagerfeuer im Licht der echten Tageszeit. Für OLED und Sofa, zum Sideloaden.
