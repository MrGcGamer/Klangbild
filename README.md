# Klangbild

Android-TV-App für Home Assistant und Music Assistant: zeigt, was gerade läuft – das Cover groß, Titel und Künstler in ruhiger Typografie.

Besonders: Der Hintergrund fließt in den Farben des Covers, Hue-Lichtleisten hinter dem Fernseher leuchten mit, Hörbücher zeigen ihre Kapitel. Gemacht für OLED und das Sofa. Zum Sideloaden.
