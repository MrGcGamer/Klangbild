# Klangbild

Android-TV-App für Home Assistant und Music Assistant: zeigt, was gerade läuft – das Cover groß, Titel und Künstler in ruhiger Typografie.

Besonders: Farben des Covers, mitleuchtende Hue-Leisten, Hörbücher mit Kapiteln. Bei Pause wird der Fernseher zum Fensterblick: Papierlandschaft im Licht der echten Tageszeit. Für OLED und das Sofa, zum Sideloaden.
